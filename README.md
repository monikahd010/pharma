Pharma Production Management System

A web-based application designed to manage pharmaceutical production, inventory, batches, quality control, and stock records in one centralized system.

🚀 Features

- 🔐 User authentication and login
- 📦 Inventory and product management
- 🧪 Batch and quality control management
- 📋 Stock log tracking
- 📊 Analytics dashboard
- 📈 Data comparison and reporting
- ⚙️ Settings and system management

🛠️ Technologies Used

Technology| Purpose
Python| Backend programming
Flask| Web application framework
SQLite| Database
HTML & CSS| Frontend
JavaScript| Interactive functionality
Jinja2| Dynamic HTML templates
Chart.js| Data visualization

▶️ How to Run

1. Clone the repository

git clone https://github.com/monikahd010/pharma.git

2. Open the project folder

cd pharma

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python app.py

5. Open it in your browser

Go to the local address shown in the terminal.

🎯 Project Objective

The goal of this project is to provide a centralized web-based solution for managing pharmaceutical production activities, reducing manual record keeping, and providing useful insights through an analytics dashboard.
